# svc-dashboard 文件浏览器重做（home 起点独立页 + 文本预览 + 精致 UI）— 完整任务目标

## 一、背景（用户拍板）

svc-dashboard（~/development/svc-dashboard/dashboard.py，:80，单文件内嵌前端）。
现在 ツール 页里的文件浏览是内嵌小节，用户要求改造成**独立功能页**：
- 一个**按钮入口**（工具页里放「文件」大按钮/卡片，点击进入独立文件浏览视图）
- 从 **/home/tetsuya（home 目录）** 开始浏览
- **文本文件打开预览**（.txt/.md/.log/.json/.py/.js/.html/.css/.sh/.yml/.toml/.conf 等）
- **好看、精致、功能齐全**——按 iOS 文件 App 的质感做

## 二、UI/交互设计

### 入口
- ツール页放一张显眼的入口卡（图标+「ファイル/文件」+副标题"浏览服务器文件"），
  点击 push 进入文件浏览视图（全屏接管 ツール 页内容区，顶部返回按钮 ← 返回工具页；
  或独立子路由 #tools/files）。桌面端同样可达（工具页网格里的一张卡）。

### 浏览器主体（移动优先，桌面双栏）
- **顶栏**：← 返回 | 当前目录名（大字）| 面包屑（可点跳级，横向滚动）| 搜索框（过滤当前目录）
- **列表**（移动）/ **表格+侧栏详情**（桌面 ≥1024：左列表右预览双栏）
  - 目录：文件夹图标 + 名称 + 项数 + mtime（相对时间：3分钟前/昨天/8月1日）
  - 文件：类型图标（按扩展名：文本/图片/json/log/压缩包/未知）+ 名称 + 人类可读大小 + mtime
  - 隐藏文件（.开头）：默认折叠，顶栏「···」菜单里开关（记住选择）
  - 排序：名称/时间/大小/类型，顶栏切换；目录永远在文件前面
  - 空目录友好提示；加载骨架屏；出错（权限）显示行内错误卡
- **交互**：
  - 点目录进入；点文本文件→打开预览；点图片→图片预览（已有能力复用）
  - 行左滑（移动）/hover 按钮（桌面）：复制路径、下载（GET 已有）
  - 顶部下拉回到上级（面包屑点击）；回到 home 按钮（🏠 一键回 /home/tetsuya）

### 文本预览（核心新功能）
- 打开方式：覆盖式阅读视图（顶栏 ← 返回列表 | 文件名 | 大小 | ··· 菜单）
- **语法高亮**：轻量自写（零依赖，不引 CDN）——json/yaml/toml 彩色、md 标题/代码块/
  链接着色、代码类按关键字/字符串/注释三色（够用即可，不追求 IDE 级）
- **大文件保护**：>2MB 提示"文件较大，仅预览前 2MB"+截断；二进制（含 NUL 前探测）
  提示"二进制文件不支持预览"
- 行号（等宽字体，可关）；自动换行开关（记住偏好）；字号 +/-（记住）
- 顶部吸附搜索：在文件内查找下一个（高亮+计数 n/m）
- 编码：UTF-8 为主，检测 GB18030 乱码时提供"以 GB18030 重开"按钮（NAS/传奇配置文件是 GB18030）
- 底部状态栏：行数/大小/编码/mtime
- ··· 菜单：复制全文/复制路径/下载原文件/在系统里用其他工具打开的 URL 复制

### 视觉质感（精致 = 细节）
- iOS 风：大圆角(12px)卡片、hover/按压态 scale(0.98)+背景变化、列表行分隔线极淡、
  图标统一 SVG（仓库已有 icon() 体系，风格一致 stroke=currentColor）
- 转场动画：进入目录 push-slide（列表右滑入），返回反向；预览打开 fade+slide-up
  （respect prefers-reduced-motion）
- 触觉反馈（haptic）复用现有
- 明暗主题全适配（今天刚做完 CSS 变量化，全部用 var(--*)）

## 三、后端

- 复用/扩展现有 `/api/fs/list`：支持 `?path=` 任意 home 下路径、返回 mtime/size/
  is_dir/项数；`/api/fs/file` 支持 text=true 返回 UTF-8 文本（带 encoding 检测标记）
- **安全边界（不变的红线）**：
  - 根白名单：**/home/tetsuya**（含子目录）+/tmp；拒绝其他（含 /etc /root /proc）
  - 路径穿越防护（resolve 后必须仍在白名单内）；符号链接跟随但同样校验终点
  - 敏感文件拒绝列表：.env*、*key*、*secret*、*.pem、id_rsa*、credentials*、
    .git/config、known_hosts → 404（list 显示但打开 404？——不：列表也直接不显示，
    与现有实现保持一致；如现有实现是显示但404，维持现状并在报告注明）
  - 只读：无上传/无删除/无重命名（明确不做）
- API 响应加 `parent`（上级路径）便于面包屑
